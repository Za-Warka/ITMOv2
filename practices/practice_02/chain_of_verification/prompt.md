Базовые правила (истина по умолчанию для ссылок внутри документа)
- SEC-1: перед вызовом внешнего LLM из diff удаляются токены/пароли/ключи.
- API-1: diff > 20 000 символов → HTTP 413 без вызова LLM.
- REL-1: внешний LLM таймаут 10 с; ошибка преобразуется в контролируемый ответ.
- OUT-1: ответ содержит summary, risks (≤3, с file, line, evidence, risk), checks.
- QA-1: риски включаются только если подтверждены diff или правилом.
- OBS-1: логи — только request_id, длительность, статус; содержимое diff/ответа не логируется.
