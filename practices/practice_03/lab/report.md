1. Как запустить тесты?

Команда: make test или python3 -m unittest -v

Источник:
- demo/Makefile
- demo/README.md

2. Что будет при пустом имени подписчика?

Ответ: Поднимется исключение ValueError("empty name").

Подтверждение кодом:
```python
if not name.strip():
    raise ValueError("empty name")
```

Источник:
- demo/service.py:5-7

3. Где реализован unsubscribe? Проверь предпосылку вопроса.
Функция unsubscribe не реализована.
Подтверждение: функция отсутствует в service.py, только есть subscribe()

4. Какая CI-система запускает тесты?
CI-система не настроена. Тесты запускаются локально командой `make test` (или `python3 -m unittest -v`).

5. Сохраняются ли подписки после перезапуска?
Нет, не сохраняются.
subscribers = set() — глобальная переменная, создаётся заново при каждом импорте модуля. Нет персистентности (БД, файлы, cache).
