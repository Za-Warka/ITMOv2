# Proposal

## Why

Repo Atlas сейчас работает как гостевое приложение: пользователь вручную вводит репозиторий, а данные GitHub живут только в текущем запросе и кэше процесса. Личный кабинет даст устойчивую точку входа в продукт: пользователь сможет войти через GitHub, увидеть доступные публичные репозитории и открыть атлас нужного проекта; поиск по `@login` позволит изучать других пользователей без ручного поиска на GitHub.

## What Changes

- Добавить отдельный Go HTTP-бэкенд для авторизации, сессий, профиля и запросов к GitHub.
- Реализовать серверный вход через GitHub OAuth с HttpOnly-сессией.
- Добавить SQLite-хранилище пользователей, сессий и временного кэша публичных репозиториев.
- Добавить API личного кабинета со списком публичных репозиториев текущего пользователя.
- Добавить точный поиск GitHub-пользователя по форме `@login` и выдачу его публичных репозиториев.
- Добавить во frontend состояние авторизации, экран личного кабинета и переход из репозитория в существующую карту Repo Atlas.
- Сохранить текущий гостевой сценарий анализа репозитория и демо-режим.
- Не включать в MVP приватные репозитории, запись в GitHub, организации, email-адреса и полнотекстовый fuzzy-поиск.

## Capabilities

### New Capabilities

- `user-auth`: вход и выход через GitHub, локальный профиль и безопасная сессия.
- `user-repositories`: получение и отображение публичных репозиториев авторизованного пользователя.
- `github-user-search`: точный поиск пользователя по GitHub login с префиксом `@` и выдача публичных репозиториев.

### Modified Capabilities

- Нет: текущий гостевой анализ репозитория сохраняется без изменения его требований.

## Impact

- Новый каталог Go-бэкенда с HTTP API, GitHub client, SQLite migrations и тестами.
- Новые переменные окружения для OAuth, сессий и базы данных.
- Изменения в Next.js UI и маршрутизации для `/account`, входа и поиска пользователей.
- Новая серверная зависимость от GitHub OAuth и REST API; токены и секреты не передаются в браузер.
- Потребуется настроить reverse proxy или единый origin между Next.js и Go API.
