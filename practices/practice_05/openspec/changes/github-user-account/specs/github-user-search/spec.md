# Spec Delta

## Purpose

Позволяет искать GitHub-пользователя по однозначному тегу `@login` и просматривать его публичный профиль и репозитории. Поиск не должен притворяться поиском по имени или рейтингом разработчиков.

## ADDED Requirements

### Requirement: Normalize user tag
Система SHALL принимать тег с одним ведущим `@`, удалять этот префикс, проверять допустимый формат GitHub login и отклонять пустые, составные или небезопасные значения.

#### Scenario: Valid tag
- **WHEN** пользователь вводит `@octocat`
- **THEN** система запрашивает пользователя с login `octocat`

#### Scenario: Invalid tag
- **WHEN** пользователь вводит `octocat/name`, `@@octocat` или строку с недопустимыми символами
- **THEN** система показывает ошибку валидации без запроса по произвольному URL

### Requirement: Find public GitHub user
Система SHALL возвращать публичные сведения найденного GitHub-пользователя и не SHALL раскрывать email или access token.

#### Scenario: User exists
- **WHEN** GitHub находит точный login
- **THEN** API возвращает GitHub ID, login, отображаемое имя, avatar URL, профиль и публичные счётчики, если они доступны

#### Scenario: User does not exist
- **WHEN** GitHub не находит точный login
- **THEN** API возвращает `user_not_found` с понятным сообщением

### Requirement: Show searched user repositories
Система SHALL возвращать для найденного пользователя только публичные репозитории с основными метаданными и ссылкой на GitHub.

#### Scenario: User has public repositories
- **WHEN** найденный пользователь имеет доступные публичные репозитории
- **THEN** ответ содержит список этих репозиториев и позволяет открыть выбранный репозиторий в Repo Atlas

#### Scenario: User has no public repositories
- **WHEN** у найденного пользователя нет публичных репозиториев
- **THEN** система показывает профиль и явно сообщает, что публичные репозитории отсутствуют

### Requirement: Search result privacy
Система SHALL не считать количество найденных репозиториев оценкой качества пользователя и SHALL отображать их как публичные данные GitHub с указанием источника.

#### Scenario: Search result is shown
- **WHEN** frontend отображает профиль пользователя
- **THEN** интерфейс содержит ссылку на GitHub и не приписывает пользователю языки, коммиты или достижения, которые не получены из соответствующих данных
