# Feature Specification: Ссылка на эпоху

**Feature Branch**: `practice_05`
**Created**: 2026-10-28
**Status**: Reviewed
**Input**: Реализовать фичу 1 — поделиться репозиторием на выбранной дате.

## User Scenarios & Testing

### User Story 1 — Открыть ту же эпоху (Priority: P1)
Посетитель делится состоянием карты без регистрации.
**Why this priority**: ссылка позволяет показать конкретный момент истории.
**Independent Test**: открыть созданную ссылку в новой вкладке.
**Acceptance Scenarios**:
1. Given выбранная дата, вкладка и боты, When открыта ссылка, Then после загрузки восстановлены дата с точностью до миллисекунды, вкладка и боты; воспроизведение остановлено.
2. Given синтетическое демо с выбранной культурой, When открыта ссылка, Then демо и культура восстановлены без запроса истории GitHub.

### User Story 2 — Получить ссылку при ограничениях браузера (Priority: P2)
**Why this priority**: копирование может быть запрещено.
**Independent Test**: запретить буфер обмена и скопировать текст вручную.
**Acceptance Scenarios**:
1. Given доступный буфер, When нажата кнопка, Then показано подтверждение только после успешного копирования.
2. Given отказ буфера, When нажата кнопка, Then доступно подписанное поле ссылки для ручного копирования.

### Edge Cases
Некорректный репозиторий даёт существующую ошибку загрузки. Некорректная дата игнорируется с сообщением; неизвестная вкладка, настройка ботов или культура заменяется безопасным значением. Дата вне охвата ограничивается ближайшей границей с сообщением. Пустой период и один момент поддерживаются. При смене проекта устаревший ответ не восстанавливает старую дату.

## Requirements

### Functional Requirements
- **FR-001**: Ссылка MUST включать источник, точную дату UTC, вкладку, ботов; для демо — культуру, только если она изменена вручную.
- **FR-002**: Состояние MUST восстанавливаться после успешной загрузки нужного источника без автозапуска; ссылка только с репозиторием сохраняет старое поведение.
- **FR-003**: Невалидные параметры и выход за охват MUST обрабатываться согласно Edge Cases; сторонние параметры и секреты в созданную ссылку не включаются.
- **FR-004**: Кнопка MUST сообщать успех копирования или предоставлять поле для ручного копирования; во время загрузки создание ссылки недоступно.
- **FR-005**: Реальная ссылка MUST предупреждать о загрузке актуальной истории и возможном изменении данных; снимок не сохраняется.
- **FR-006**: Управление MUST быть доступно клавиатурой и без горизонтальной прокрутки на ширинах 360, 768, 1440.

### Key Entities
Состояние эпохи: источник, дата, вкладка, учёт ботов, культура демо. Охват: начало и конец доступных данных.

## Success Criteria

### Measurable Outcomes
- **SC-001**: Все пять составляющих состояния демо совпадают после открытия ссылки.
- **SC-002**: При отказе копирования ссылка доступна для ручного выделения за одно действие.
- **SC-003**: Все граничные сценарии имеют определённый исход, страница остаётся работоспособной.

## Assumptions
Камера и выделенное здание не сохраняются. URL обновляется только при создании ссылки; Back/Forward между состояниями не входит в объём. Используется актуальный снимок сервера; демо не требует Go API. Авторизация не нужна.
