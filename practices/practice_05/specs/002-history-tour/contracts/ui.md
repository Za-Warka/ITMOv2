# UI contract
«Начать экскурсию» disabled при loading или отсутствии остановок. При empty текст «Для экскурсии нужны наблюдаемые коммиты». Активно: «Остановка N из M», «Назад», «Далее», «Завершить экскурсию»; края disabled. Текст события — в region «Экскурсия по истории», дата UTC, реальная ссылка на github.com/{snapshot.name}/commit/{sha}, либо «Синтетическое событие демо». Partial имеет явное предупреждение.
Все действия — native button, видимый focus, live status только при смене остановки. Не требует hover. Ссылка фичи 1 сохраняет текущую дату экскурсии, но не её активность.
